# TwoTower (loopback): Last.fm 1K и MovieLens-100k

Основной протокол: `test/seen=train+val`, метрика `recall`; в таблицах значения при K = 10 / 50 / 100.

## 1. MovieLens-100k

Сплит `global` — общая временная шкала, как у авторов:

|  | @10 | @50 | @100 | польз. |
|---|---|---|---|---|
| Гиперпараметры авторов (3 эпохи, батч 4096) | 0.0144 | 0.0525 | 0.0864 | 166 |
| Подбор по val: батч 2048, эпоха 4 | 0.0195 | 0.0821 | 0.1351 | 166 |
| — из них с историей в train | 0.0149 | 0.1044 | 0.1729 | 69 |
| — из них без истории (холодный старт) | 0.0228 | 0.0663 | 0.1082 | 97 |
| То же с поправкой logQ, которой нет у авторов: эпоха 3 | 0.0833 | 0.2171 | 0.3110 | 166 |
| Бейзлайн: популярное | 0.0615 | 0.1992 | 0.3145 |  |
| Бейзлайн: случайная выдача | 0.0063 | 0.0316 | 0.0633 |  |

Сплит `user` — по времени внутри каждого пользователя:

|  | @10 | @50 | @100 | польз. |
|---|---|---|---|---|
| Гиперпараметры авторов (3 эпохи, батч 4096) | 0.0116 | 0.0475 | 0.0852 | 943 |
| Подбор по val: батч 2048, эпоха 14 | 0.0413 | 0.1659 | 0.2877 | 943 |
| То же с поправкой logQ, которой нет у авторов: эпоха 139 | 0.0885 | 0.3158 | 0.4721 | 943 |
| Бейзлайн: популярное | 0.0600 | 0.1835 | 0.2978 |  |
| Бейзлайн: случайная выдача | 0.0063 | 0.0316 | 0.0633 |  |

## 2. Сравнение

|  | @10 | к случайной выдаче | к популярному |
|---|---|---|---|
| MovieLens-100k, сплит global | 0.0195 | ×3.1 | ×0.3 |
| MovieLens-100k, сплит user | 0.0413 | ×6.5 | ×0.7 |

«К случайной выдаче» и «к популярному» — во сколько раз модель лучше бейзлайна при K = 10 (для MovieLens взят запуск с подбором по val). Каталоги отличаются на три порядка: 1.5 млн треков против 1.7 тыс. фильмов, поэтому датасеты сравниваются по этим отношениям, а не по самим значениям метрики.
